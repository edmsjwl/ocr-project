UI 아이콘 사이즈: 16 / 20 / 24 / 28 / 32px(`Icon/Frame` 스와치 기준). Graphic(삽화형) 아이콘 사이즈: 24 / 32 / 48 / 64 / 84px.

개별 아이콘 글리프의 내부 벡터·색상은 에셋(SVG)으로만 제공되어 코드로 조회되지 않는다(`[Figma에서 확인 불가]`). 이름 규칙은 `Icon/이름/사이즈`.
